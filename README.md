# Podkop config auto updater

Команда установки — выполните в SSH-терминале роутера от `root` после установки Podkop:

```sh
uclient-fetch -O /tmp/podkop-config-auto-updater-install.sh https://raw.githubusercontent.com/hayOfLife/podkop-config-auto-updater/main/install.sh && sh /tmp/podkop-config-auto-updater-install.sh
```

[Подробная инструкция установки](docs/operations.ru.md#установка-и-обновление)

Дополнение к Podkop для OpenWrt. Загружает конфигурацию из закрытого GitHub-репозитория или по прямой HTTPS-ссылке, объединяет списки и обновляет параметры секций `main` и `notUnderSanctions`, DNS и загрузки списков.

## Установка

Сначала установите Podkop и настройте доступ роутера к интернету. [Установочный скрипт](install.sh) определяет OpenWrt 24.10 / 25.12, скачивает подходящий IPK / APK из [релиза](https://github.com/hayOfLife/podkop-config-auto-updater/releases/latest), проверяет SHA-256 и устанавливает пакет. APK — пакет OpenWrt, не Android. Команды запуска находятся в [инструкции администратора](docs/operations.ru.md).

При ручной установке загрузите пакет через **Система → Пакеты → Загрузить пакет**, затем обновите страницу LuCI. Появится **Службы → Podkop config auto updater**. Флажки работы, автоматического удаления и **«Контролировать доступ к OpenAI»** включены; **«Выключить ip v6»** по умолчанию выключен. Пакет не содержит личных серверов или токена; введите ссылку и токен по [инструкции настройки GitHub](docs/github-setup.ru.md).

Подробные команды установки, обновления, удаления и восстановления находятся в [инструкции администратора](docs/operations.ru.md). На реальном роутере установка и работа этой версии ещё не проверены.

## Что делает программа

- Добавляет записи к существующим без новых дублей.
- Начиная с 0.1.3 понимает комментарии `//` и `/* */` для заголовков групп в конфиге.
- Начиная с 0.2.0 переносит заголовки `{"comment": "Название группы"}` из массивов доменов и подсетей в текстовые поля Podkop как строки `// Название группы`.
- Удаляет только записи с `delete`, если включено автоматическое удаление.
- Применяет две секции одной транзакцией, ставит `notUnderSanctions` перед `main` и отклоняет перенос записи, если необходимые удаления или поля запрещены локально.
- Обновляет раз в день, 3 дня, неделю или 30 дней; по умолчанию ежедневно.
- Выбирает случайную минуту от **03:00 до 03:30** по времени роутера для каждого планового запуска. Выбранное время хранится в RAM: переживает перезапуск службы, но после перезагрузки роутера выбирается заново.
- Позволяет запустить обновление вручную; с 0.2.2 применение идёт в фоне с отображением этапов, а успешный результат появляется после завершения.
- Кнопка **«Тест соединения»** скачивает файл и показывает результат разбора JSON и проверки формата, сохраняя настройки Podkop без изменений.
- Кнопки **«Обновить подкоп»** и **«Обновить себя»** обновляют программы из официальных релизов в фоне, проверяют SHA-256 и сохраняют резервную копию настроек.
- Поддерживает произвольные параметры обеих секций и шесть разрешённых общих настроек Podkop.
- Позволяет отдельной галочкой запретить применение каждого параметра из конфига; по умолчанию все разрешены.
- Контролирует доступ к OpenAI через `notUnderSanctions` и выбирает другой узел при подтверждённом региональном отказе или повторяющейся сетевой ошибке. Нужны работающий Clash API и подтверждение маршрута конкретного запроса; `main` не переключается.
- При включении «Выключить ip v6» сохраняет и отключает IPv6, при снятии галочки восстанавливает прежнее состояние.
- Проверяет файл целиком перед изменениями, сохраняет резервную копию и перезапускает Podkop только после изменения настроек.

Исходники программы открыты. Файл с личными серверами хранится в **отдельном закрытом репозитории**. Токен нужен только на роутере и должен иметь право чтения Contents только выбранного репозитория.

## Переход на две секции

Сначала обновите дополнение до **0.2.0 или новее**, затем замените ссылку на конфиг схемы 3: `config/split.json` или `config/split.jsonc` своего закрытого проекта. Сохраните настройки, выполните **«Тест соединения»**, затем **«Обновить сейчас»**. Старые `config/main.json` / `main.jsonc` остаются в схеме 2 для загрузчиков 0.1.x. [Порядок перехода и ограничения](docs/operations.ru.md#переход-на-main-и-notundersanctions).

`notUnderSanctions` использует отдельный пул для сервисов с требованиями к региону выхода. При включённом контроле OpenAI программа раз в три минуты проверяет запрос без API-ключа через эту секцию и управляет её внешней группой выбора вместо URLTest. Тип секции и пул URLTest сохраняются. Успех подтверждает только достижение проверки авторизации OpenAI; Claude, Gemini, аккаунты и функции моделей так не проверяются. Страна сервера автоматически не определяется. [Как устроены проверка и переключение](docs/openai-check.ru.md).

В **0.2.2** исправлен отказ проверки на OpenWrt, где команда `sleep` не принимает дробные секунды: пауза выполняется через ucode. Кнопка «Обновить сейчас» показывает ход применения конфига и отличает завершённый результат от потери связи с LuCI. Обновите дополнение и страницу браузера; ссылка и токен остаются прежними. Проверки двух версий OpenWrt выполнены в изолированной среде, установка исправления на реальный роутер пока не проверена.

Широкие сети CDN могут направить сюда и часть сервисов `main`. Разделение и контроллер доступны начиная с версии **0.2.0**; установка этой версии и работа на реальном роутере ещё не подтверждены.

Применение UCI-конфига и обновление самого Podkop — разные функции. Начиная с версии **0.2.1** кнопка **«Обновить подкоп»** определяет установленную ветку: `podkop` обновляется из `itdoginfo/podkop`, `podkop-exp` — из `podkop-net/podkop-experimental`. Она устанавливает только более новую версию этой же ветки, проверяет подходящий пакет и SHA-256. При одновременной установке обеих веток обновление останавливается без их удаления. В 0.2.0 обновление Experimental ещё не поддерживалось. Новое поведение на роутере не проверено. [Подробности совместимости](docs/development.ru.md#совместимость-и-ограничения).

С версии 0.1.4 расписание, время последнего обновления, статусы, скачанные файлы и автоматические резервные копии хранятся в RAM (`/tmp/podkop-config-auto-updater`) и исчезают после перезагрузки роутера. Там же хранится состояние контроля OpenAI: предыдущий выбор, счётчики ошибок и временное исключение узлов. После перезагрузки выбирается новое ближайшее ночное окно. На флеш-памяти остаются настройки UCI с токеном, применённый конфиг Podkop и данные восстановления IPv6. Старые копии в `/etc/podkop-config-auto-updater` автоматически не удаляются; собственный файл состояния Podkop программа не удаляет.

# Как создать закрытый репозиторий и получить токен

Эта инструкция помогает подключить файл настроек к **Podkop config auto updater**. Нужны аккаунт GitHub, права владельца репозитория и доступ администратора к веб-интерфейсу роутера.

## Создайте репозиторий конфигурации

1. Откройте [создание репозитория GitHub](https://github.com/new).
2. Укажите имя, например `podkop-config-auto-updater-config`, выберите **Private** и создание README, затем нажмите **Create repository**.
3. В новом репозитории выберите **Add file → Create new file**. Имя файла — `config/main.json`.
4. Вставьте [пример конфигурации](../examples/main.json), замените демонстрационные записи своими и сохраните файл кнопкой **Commit changes**. Точный формат описан в [справочнике конфига](config-format.ru.md).
5. Откройте сохранённый файл и скопируйте адрес из браузера. Поддерживается ссылка вида `https://github.com/OWNER/REPOSITORY/blob/main/config/main.json`. `OWNER` — ваш логин, `REPOSITORY` — имя закрытого репозитория.

Если репозиторий и файл уже существуют, повторно создавать их не нужно. Не включайте публичный доступ: ссылки серверов могут содержать учётные данные. Изменения сохраняются в истории Git.

## Получите токен только для чтения

1. Откройте [создание fine-grained personal access token](https://github.com/settings/personal-access-tokens/new). Путь через меню: аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Назовите токен, например `podkop-config-auto-updater-router`, и выберите срок действия. После его окончания создайте новый токен и замените его на роутере.
3. В **Resource owner** выберите владельца закрытого репозитория.
4. В **Repository access** выберите **Only select repositories**, затем только репозиторий с конфигурацией.
5. В **Repository permissions** выдайте **Contents → Read-only**. Право Metadata добавляется автоматически. Права записи и доступ к другим репозиториям не нужны.
6. Нажмите **Generate token** и скопируйте полученное значение. GitHub показывает его один раз.

Здесь нужен персональный токен доступа, а не пароль GitHub и не Actions Secret. Для репозитория организации может потребоваться одобрение её администратора. Эти ограничения описаны в [документации GitHub о токенах](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens). Чтению файла достаточно [разрешения Contents: read](https://docs.github.com/en/rest/repos/contents#get-repository-content).

## Подключите роутер

1. Откройте **Службы → Podkop config auto updater**.
2. В **Ссылка на файл конфига** вставьте адрес файла, скопированный из GitHub.
3. В **Токен GitHub** вставьте полученный токен.
4. Нажмите **Сохранить и применить**, затем **Обновить сейчас**.

При успехе появится результат проверки и количество добавленных и удалённых записей. Это проверяет загрузку и сохранение настроек; доступность VPN-серверов программа самостоятельно не тестирует. Podkop выполняет свои штатные проверки URLTest.

Галочки «Работать» и автоматического удаления по умолчанию включены; «Выключить ip v6» выключена. Автоматическое обновление выполняется раз в день в случайную минуту от 03:00 до 03:30 по времени роутера. Часовой пояс настраивается в системных настройках OpenWrt.

Токен хранится в `/etc/config/podkop_config_auto_updater` с правами `600`, без шифрования на диске. Администратор роутера и его резервная копия могут содержать этот секрет. Не публикуйте его и не вставляйте в ссылку. Для отзыва удалите токен на GitHub; конфигурация Podkop при этом сохранится, а новые загрузки прекратятся.

## Если загрузка не проходит

- **Файл не загружен:** проверьте, что файл существует в указанной ветке, токен не истёк и ему разрешён доступ именно к этому репозиторию.
- **Неверная ссылка GitHub:** используйте адрес файла с `/blob/main/`. В этой версии имена веток со слешем и пробелы в пути не поддерживаются.
- **Несохранённые изменения Podkop:** сохраните или отмените их в LuCI, затем повторите обновление.
- **Личный сервер:** используйте прямую HTTPS-ссылку на JSON без перенаправления; поле токена GitHub оставьте пустым. Авторизация личного сервера в версии 0.1.0 не реализована.

Исправление полей и повторное сохранение меняет только настройки загрузчика. Чтобы отменить уже применённое изменение Podkop, используйте [инструкцию восстановления](operations.ru.md#восстановление).
